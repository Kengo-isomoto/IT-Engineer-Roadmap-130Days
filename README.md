* # Day6

**📅 日付**
2026/7/28

**⏰ 学習時間**
記録なし

**📚 学習内容**

* ITパスポートのテキストを完読し、試験範囲の全体像を把握した。
* 用語はまだ十分に定着していないため、過去問を解きながら英単語本来の意味と関連付けてメモを取る学習方法を開始。
* YouTubeでIT用語を聞き流す学習も取り入れ、耳から繰り返し聞くことで用語を覚えやすくなることを実感した。
* テキスト中心のインプット学習を終え、過去問中心の学習へ移行した。
* 過去問集はS（ストラテジ）100問、M（マネジメント）67問、T（テクノロジ）138問の全305問。
* 全305問を10セットに分け、S → M → Tの順番で学習する。
* 採点後、間違えた問題や理解できていない用語をノートに書き出して復習する。
* 次のセットでは新しい問題に加えて、前回完全に分からなかった問題を再度解き、理解して正解できるまで繰り返す方式で学習する。

**📊 過去問 1セット目**

* S（ストラテジ）：7 / 10問
* M（マネジメント）：3 / 7問
* T（テクノロジ）：9 / 14問
* 合計：19 / 31問正解
* 正答率：約61％

**✅ 理解できたこと**

* テキストを完読し、ITパスポートで扱われる分野の全体像を把握できた。
* 用語だけを暗記するより、元になった英単語の意味と関連付けることで理解・記憶しやすくなることが分かった。
* YouTubeなどで用語を繰り返し聞く方法も、用語の定着に効果を感じた。
* 過去問を解くことで、理解できている部分と知識が不足している部分を具体的に把握できるようになった。

**📝 復習が必要なこと**

* 1セット目で間違えた問題を確認し、特に「完全に分からなかった問題」を重点的に復習する。
* 分からなかった用語は英単語の意味と関連付けてノートに整理する。
* M（マネジメント）は3 / 7問と正答率が低かったため、間違えた内容を重点的に確認する。
* 完全に分からなかった問題は、理解して自力で正解できるまで次回以降の問題数に加えて繰り返す。

**🎯 Day7 学習予定**

* 2セット目の新規問題として、S：10問、M：7問、T：14問の計31問に挑戦する。
* これに1セット目で完全に分からなかった問題を追加して解く。
* 間違えた問題は採点後に原因を確認し、関連用語をノートに書き出す。
* 「正解したか」だけでなく、「内容を理解したうえで正解できたか」を確認する。
* 理解できなかった問題は次セットにも持ち越し、自力で正解できるまで反復する。
