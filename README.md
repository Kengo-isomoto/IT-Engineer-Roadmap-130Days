* テクノロジ分野：138 / 138問 復習完了
* 令和8年度 過去問（テクノロジ）：46問
* 正答率：約63％

**✅ 理解できたこと**

* テクノロジ138問を一通り復習し、基本的な用語については以前より知識が定着してきた。

* 何も分からなかった問題は、答えだけを覚えず、必要な基礎知識から深掘りする。
* 特に関係データベースの問題を重点的に復習する。
* 表の中から主キー・外部キーを判断する問題を理解する。
* IF関数について、条件・真の場合・偽の場合の対応を理解し、問題文が変わっても解けるようにする。
* 次回は用語の復習に加えて、その知識を使って応用問題を解けるか確認する。

- OSS、コピーレフトについて復習

**✅ 理解できたこと**

- LPWAは広範囲・省電力、BLEはBluetoothの省電力通信
- PKIでは認証局が電子証明書によって公開鍵の正当性を保証する
- ゼロトラストは内部・外部を問わず、最初から信用せずに認証する考え方
- SQLインジェクションなどへの対策として、入力内容を無害化するサニタイジングを理解
- OSSは必ずしも無料ではなく、ライセンス条件に従って利用・改変・再配布できる
- コピーレフトでは派生ソフトウェアを配布する際に同じライセンスを引き継ぐ
- 差分バックアップと増分バックアップの違いを理解
- 関係データベースでは外部キーが参照する主キー側のデータを先に登録する
- バックプロパゲーションは誤差を逆方向に伝え、重みを調整して誤差を小さくする
- 演繹推論は大きなルールから個別の結論を導く
